# Senda Ninja · Batalla del Bosque

Versión web del juego (la misma que lleva la app de Android). Se juega desde el navegador del celular, en vertical.

- Equipos de 3 ninjas; cada equipo empieza con un pergamino Sol o Luna y tiene que robar el otro.
- Solo contra bots, o multijugador por internet con código de sala (iPhone, Android y PC en la misma sala).
- En iPhone: abrir en Safari y usar **Compartir → Añadir a pantalla de inicio** para verlo a pantalla completa.

Esta carpeta es el sitio publicado con GitHub Pages: `index.html` y `game.js` son el juego ya empaquetado.
